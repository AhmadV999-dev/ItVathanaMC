# VATHANA

Official website of **VATHANA** (Vathana Gaming), a Minecraft Bedrock creator from Cambodia.
It has my social media, groups, mods, projects and the mods I use.

**Website: https://vathanacoder.github.io/ItVathanaMC/** 

## Features

- Home page with About me, Social media, Groups, My mods, My projects and What mods I use
- Help page with Q&A and a contact link
- Soft neumorphism design in dark and light mode
- Popups for social accounts, groups and mod info
- "Theme song" music player with a spinning disc, play, pause, stop and a seek bar (the song loops)
- Works well on phones and on computers

## Project structure

```
index.html, help.html   The two pages
style.css               Design (neumorphism, dark and light)
script.js               Popups, theme switch, music player
assets/                 Pictures, icons, fonts and the theme song
public/                 Copy of the site files that gets published
config/                 Build settings
src/, server/, scripts/ Site framework and build tools
```

When you add a picture or song, put it in both `assets/` and `public/assets/`.

## Edit the content

Mods, projects, social links and groups are all in `script.js`. The page text is in `index.html` and `help.html`.
